## Ручные проверки

Выполнены на сборке `npm run dev` и `npm run build && npm run preview`.

**Публичный контур**

- Главная: первый экран, посимвольное появление заголовка, дрейф фона, переход к разделу «Что можно сделать» по якорю.
- Переходы между всеми пятью разделами — в обе стороны, включая кнопку «назад» браузера.
- Форма подачи: пять шагов вперёд и назад, валидация каждого шага, drag & drop, неверный формат, файл больше 12 МБ, предпросмотр и замена файла, экран успеха, копирование номера и кода.
- Уход со страницы с черновиком: диалог подтверждения, отмена и подтверждение, возврат браузером.
- Проверка статуса: пустые поля, неверная пара, демонстрационная пара, все семь статусов, отклонённое обращение.
- Контакты: телефонные и почтовые ссылки, раскрытие фотографии по маске.

**Служебный контур**

- Вход: неверные данные, демонстрационные данные, показ пароля.
- Реестр: поиск, Ctrl/Cmd + K, четыре фильтра, сброс, пустой результат.
- Карточка дела: полный цикл `NEW → ACCEPTED → IN_PROGRESS → DECISION → ANSWERED → CLOSED`, отклонение с обязательной причиной, служебная заметка, просмотр вложения.
- Синхронизация между вкладками через событие `storage`.

**Темы, доступность, адаптация**

- Переключение темы на каждой странице; круговая волна; запоминание после перезагрузки; отсутствие вспышки неверной темы при первой отрисовке.
- Клавиатура: ссылка пропуска, Tab по шапке и меню, удержание фокуса в ящике и модальном окне, Escape.
- `prefers-reduced-motion: reduce` — переходы, дрейф фона и появление блоков отключаются.
- Ширины: 360, 480, 768, 1024, 1280, 1440, 1920.

## Известные ограничения

- View Transitions API поддерживают Chromium-браузеры и Safari 18+. В Firefox работает резервная CSS-анимация — визуально она мягче, но без сшивки шапки.
- `color-mix()` требует Chrome 111+, Safari 16.2+, Firefox 113+. В более старых браузерах часть полупрозрачных фонов статусов не отрисуется.
- Данные хранятся в `localStorage` конкретного браузера: многопользовательская работа и транзакции появятся только с настоящим backend.
